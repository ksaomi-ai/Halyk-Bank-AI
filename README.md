Репозиторий содержит готовый пайплайн для автоматического анализа банковского датасета

Возможности


Требования:
Python 3.10+

Настройка:
1. Клонируйте репозиторий:
   git clone <репозиторий>

2. Установите зависимости:
   python -m pip install -r requirements.txt

3. Подготовьте .env с ключами (если используете OpenAI/Anthropic):
   OPENAI_API_KEY=sk-...
   ANTHROPIC_API_KEY=...

4. Поместите архив датасета в папку `data/` или укажите путь при запуске.
